# Public API consumer fixture

This is a compile-validation fixture, not a demo application. `Scripts/test-terminalui-api.py` copies it into a temporary external Swift package to check the public `TerminalUI` API, including macro expansion, generic views and typed composition.

For runnable examples, see `Examples/LayoutDemo`, `Examples/RepositoryDemo` and `Examples/EngineDemo`.

The sibling `ArgumentApplicationConsumer` validates the opt-in argument-aware macro from an external package.
